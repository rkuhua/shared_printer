# 全能打印机共享管理工具 (Win7/10/11兼容版)

> **作者：R**

这是一个简单但功能强大的 Windows 应用程序，用于解决局域网内共享打印机和文件连接难、配置繁琐的问题。它不仅支持一键连接和安装打印机，还提供了一键设置共享、免密配置以及系统修复功能。

## ✨ 主要功能

### 🖨️ 连接与安装 (客户端)
- **一键连接**：支持输入 IP、用户名、密码连接服务器。
- **智能列表**：自动列出远程服务器上的所有 **打印机** 和 **共享文件夹**。
- **一键安装**：选中打印机后，点击“一键安装”，程序会自动安装驱动并将其**设为默认打印机**。
- **文件浏览**：支持直接打开共享文件夹，像本地磁盘一样浏览文件。

### 📡 共享设置 (服务端)
- **一键共享**：选中本机已安装的打印机，一键开启网络共享。
- **免密配置**：提供“一键开启免密共享”功能，自动修改组策略和注册表（启用 Guest、允许空密码、允许匿名访问），让局域网内其他电脑无需密码即可连接。

### 🛠️ 系统修复 (增强版)

程序将修复功能明确分为两类，方便用户判断：

**1. 主机端修复 (本机作为共享主机)**
- **重启打印服务**：Spooler 服务卡死时使用。
- **开启网络发现与共享**：确保本机能被搜索到。
- **一键关闭本机防火墙**：快速排除防火墙阻挡问题。

**2. 客户端修复 (本机去连接别人)**
- **一键修复连接策略 (含 Win10/11/24H2)**：
    - 解决 Win10 “阻止未经身份验证的来宾访问”。
    - 解决 Win11 24H2 无法访问共享、扩展错误等问题（自动配置 SMB 签名和明文密码策略）。
- **重启打印服务**：Spooler 服务异常时使用。

## 🚀 如何使用

### 直接运行
双击目录下的 `一键添加共享打印机.exe` 即可运行。
> ⚠️ **注意**：建议右键选择“以管理员身份运行”，否则部分高级功能（如开启免密共享、修复服务）可能会失败。

### 编译代码
如果您想修改源代码，请编辑 `PrinterManager.cs`，然后运行 `compile.bat` 重新编译生成 EXE 文件。

## 📝 常见问题

**Q: Win11 24H2 提示无法访问共享主机？**
A: 请在“一键修复工具”页面下方，点击“一键修复连接策略”按钮。

**Q: 连接时提示“找不到网络路径”？**
A: 请在主机端运行此工具，点击“开启网络发现与共享”或“一键关闭防火墙”。

## 📦 系统要求
- Windows 7 SP1 或更高版本
- .NET Framework 4.0 (Windows 10/11 自带，Win7 可能需要安装)
